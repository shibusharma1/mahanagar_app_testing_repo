# 🎓 Biratnagar Metropolitan Scholarship Management System

A full-featured Scholarship Management System developed for **Biratnagar Metropolitan City, Nepal** to manage scholarships for SEE graduates applying for their +2 education.

This project digitizes the scholarship application and approval process, helping students apply online while enabling administrators to efficiently verify applications, manage approvals, send notifications, and generate admit cards.

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/shibusharma1/mahanagar_app_testing_repo.git

# Move into the project directory
cd mahanagar_app_testing_repo

# Install dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Configure database in .env file

# Run migrations
php artisan migrate

# Start the development server
php artisan serve
```

---

## 🔐 Environment Configuration

Update your `.env` file with:

```env
APP_NAME="Scholarship System"
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost

DB_DATABASE=your_database
DB_USERNAME=your_username
DB_PASSWORD=your_password
```
